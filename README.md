# 高木和西片 RVC 干声数据集

本仓库提供高木同学与西片的干声语音素材，可用于训练 RVC 音色转换模型。

## 中文

### 数据集内容

| 目录 | 内容 | 文件数 |
| --- | --- | ---: |
| `高木同学干声数据集/高木同学干声by《Takagi san VR》/` | 高木同学干声语音 | 277 |
| `高木同学干声数据集/追加--高木同学闹钟语音包/` | 高木同学闹钟语音 | 115 |
| `西片干声数据集/初步素材/` | 西片原始语音 | 1 |
| `西片干声数据集/可用素材/` | 西片可用语音片段 | 270 |

仓库中的音频格式为 WAV 和 MP3。西片的录制视频不包含在仓库中。

## 日本語

このリポジトリには、高木さんと西片のドライボイス音声素材を収録しています。RVC の音声変換モデルの学習に利用できます。

| ディレクトリ | 内容 | ファイル数 |

| `高木同学干声数据集/追加--高木同学闹钟语音包/` | 高木さんの目覚まし音声 | 115 |
| `西片干声数据集/初步素材/` | 西片の元音声 | 1 |
| `西片干声数据集/可用素材/` | 西片の利用可能な音声素材 | 270 |

音声形式は WAV と MP3 です。西片の録画映像はこのリポジトリに含まれていません。

## English

This repository contains dry voice recordings of Takagi and Nishikata for training RVC voice conversion models.

### Dataset Contents

| Directory | Contents | Files |
| --- | --- | ---: |
| `高木同学干声数据集/高木同学干声by《Takagi san VR》/` | Takagi dry voice recordings | 277 |
| `高木同学干声数据集/追加--高木同学闹钟语音包/` | Takagi alarm voice recordings | 115 |
| `西片干声数据集/初步素材/` | Original Nishikata voice recording | 1 |
| `西片干声数据集/可用素材/` | Usable Nishikata voice clips | 270 |

The audio formats are WAV and MP3. Nishikata's recorded video is not included in this repository.
